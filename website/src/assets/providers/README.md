# Provider marks

Only marks a vendor publishes for third-party use live here, byte-for-byte as downloaded. They are imported with `?url`, so the build ships the file unchanged. Do not edit, recolour or inline them.

| File | Source | Vendor terms |
|------|--------|--------------|
| `appwrite/logomark.svg` | `https://appwrite.io/assets/logomark/logo.svg`, linked from [appwrite.io/assets](https://appwrite.io/assets) | The logomark suits places where space is too tight for the logotype. Do not alter it, and prefer a neutral background. |

Google Cloud, AWS and Cloudflare logos are not used. Google requires an approved permission request ([brand terms](https://about.google/brand-resource-center/brand-terms/)), and its [icon library](https://cloud.google.com/icons) has product icons, not the Google Cloud mark. AWS allows fair use only in plain text, with no logos ([trademark guidelines](https://aws.amazon.com/trademark-guidelines/) §13), and its Architecture Icons are for diagrams. Cloudflare logos need written permission ([trademark page](https://www.cloudflare.com/trademark/)). Those three providers appear by name only, next to TerraDart's own neutral glyphs in `src/components/landing/ProviderIcon.astro`.
