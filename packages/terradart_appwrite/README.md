Curated factory wrappers for **Appwrite** resources (the official [`appwrite/appwrite`](https://registry.terraform.io/providers/appwrite/appwrite) Terraform provider) for Dart-first Terraform stacks.

The catalog at the current provider pin (`kAppwriteProviderVersionConstraint`) is filled (every `appwrite_*` resource and data source). The weekly schema bump moves the pin to the latest 2.x release and adds a factory for each new type.

## Security & Credentials

**Credentials never appear in synth output by design.** `AppwriteProvider` has no API-key parameters; authenticate at apply time via `APPWRITE_API_KEY` or `APPWRITE_ORGANIZATION_API_KEY` environment variables.

## Installation

```yaml
dependencies:
  terradart_core: ^0.35.0
  terradart_appwrite: ^0.35.0
```

## Usage example

```dart
// lib/appwrite_infra_stack.dart
import 'package:terradart_appwrite/provider.dart';
import 'package:terradart_appwrite/storage.dart';

final class AppwriteInfraStack extends Stack {
  AppwriteInfraStack()
      : super(
          providers: [
            AppwriteProvider(
              endpoint: 'https://cloud.appwrite.io/v1',
              projectId: 'my-project',
            ),
          ],
        ) {
    add(
      AppwriteStorageBucket(
        'uploads',
        name: .literal('uploads'),
        maximumFileSize: .literal(10485760),
      ),
    );
  }
}
```

```dart
// bin/infra.dart
import 'package:my_app/appwrite_infra_stack.dart';

Future<void> main() async {
  final stack = AppwriteInfraStack();
  await stack.writeTo('tf-out');
}
```

```bash
dart pub get
dart pub global activate terradart_cli
APPWRITE_API_KEY=... terradart apply
```

## Curated surface

Curated surface is the full `appwrite/appwrite` catalog at the current pin, across project, proxy, TablesDB, dedicated PostgreSQL / MySQL / Mongo, storage, auth, functions, sites, messaging, webhooks, and backups. Provider pinned exactly at `kAppwriteProviderVersionConstraint`. `AppwriteProjectKey` is import-only (mint it in the Console, then import it into the state with `"$(terradart engine)" -chdir=tf-out import`); the quickstart does not create one.

Generated by the maintainer pipeline (`terradart-codegen wrap` against a filtered fixture); do not hand-edit files under `lib/src/`.
